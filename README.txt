
# ShopDB_Final Project

## Hướng dẫn cài đặt
1. Mở file `ShopDB_Final.sql` trong SQL Server Management Studio (SSMS).
2. Chạy script để tạo database `ShopDB_Final` và seed dữ liệu mẫu.
3. Mở solution ASP.NET Core MVC trong Visual Studio, kiểm tra `appsettings.json` để trỏ connection string về database này.
4. Chạy project và login:
   - admin / 123456
   - user1 / 123456

Ảnh mẫu nằm ở thư mục `wwwroot/images/products/`.
